# Development roadmap

Phases 01 and 02 provide the workspace, Boolean environment and bounded expression language. Implementation of each subsequent phase requires authorization.

| Phase | Scope                                                                        | Status      |
| ----- | ---------------------------------------------------------------------------- | ----------- |
| 01    | Foundation, architecture, design system, workspace and Logic Playground      | Implemented |
| 02    | Mathematical expression representation, parsing and deterministic evaluation | Implemented |
| 03    | Complete propositional logic and set theory environments                     | Planned     |
| 04    | Mathematical notebooks and reproducible experiments                          | Planned     |
| 05    | Hypothesis testing and counterexample discovery                              | Planned     |
| 06    | Graph theory and algorithm analysis                                          | Planned     |
| 07    | Linear algebra and mathematical visualization                                | Planned     |
| 08    | Calculus and numerical mathematics                                           | Planned     |
| 09    | Probability, statistics and number theory                                    | Planned     |
| 10    | Formal proof infrastructure and Lean integration                             | Planned     |
| 11    | Automata, formal languages and computability                                 | Planned     |
| 12    | Knowledge dependency graph and academic study infrastructure                 | Planned     |
| 13    | Optional local AI-assisted mathematical tutoring                             | Planned     |
| 14    | Distribution, performance, accessibility and release engineering             | Planned     |
